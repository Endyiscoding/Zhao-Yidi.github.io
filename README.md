# Yidi Zhao's Academic Website

Personal academic website for Yidi Zhao, Ph.D. Candidate in Economics at Penn State University.

- Home and introduction: `_pages/about.md`
- Research and paper abstract: `_includes/yidi-research.html`
- Research page: `_pages/publications.html` (published at `/research/`)
- Online CV: `_pages/cv.md`
- Downloadable CV: `files/YidiZhao_CV.pdf`
- Portrait: `images/yidi-zhao.jpg`
- Contact and site settings: `_config.yml`
- Navigation: `_data/navigation.yml`

Repository: [Endyiscoding/Zhao-Yidi.github.io](https://github.com/Endyiscoding/Zhao-Yidi.github.io)

GitHub Pages URL (after enabling deployment): https://endyiscoding.github.io/Zhao-Yidi.github.io/

## Local preview

```sh
sh scripts/site setup
sh scripts/site serve
```

Open http://127.0.0.1:4000. To build the production site, run `sh scripts/site build`.
See [DEPLOY.md](DEPLOY.md) for GitHub Pages configuration.
